登录按钮高光

登录与注册按钮的边缘跟随高光采用 React Bits Specular Button 的 WebGL 着色器与圆角边缘算法，由本项目适配原生交互和账号表单状态。沿用 React Bits 许可证；减少动态效果或图形能力不可用时保留静态按钮。
