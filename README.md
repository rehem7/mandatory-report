# 强制报告智能体

面向未成年人保护场景的全栈 Web 演示项目，集成 AI 问答、情景实训、普法学习与线索报告，贯通公众报告、人工复核、部门协同和监督反馈流程。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 智能问答 | 多模型切换、流式回答、官方来源检索、用户记忆及对话转报告草稿 |
| 情景实训 | 五个虚构案例、AI 角色对话、分项评分与复盘反馈 |
| 普法学习 | 制度要点、岗位案例、学习记录与个人培训台账导出 |
| 线索报告 | 分区表单、草稿保存、证据附件、匿名报告与回执查询 |
| 接收工作台 | 人工复核、部门分流、处置记录、超期及不予立案监督摘要 |
| 账号与记录 | 邮箱注册、访客使用、数据隔离及登录账号跨浏览器同步 |

## 技术实现

- **服务端**：Node.js 原生 HTTP 服务，采用模块化结构组织认证、报告、问答和实训接口，无需安装运行依赖。
- **前端**：原生 JavaScript、CSS 与 SVG，提供响应式页面、Markdown 渲染和 SSE 流式交互。
- **数据管理**：JSON 文件持久化；结合 localStorage、IndexedDB 和服务端版本检查，实现草稿恢复与并发编辑保护。
- **AI 集成**：兼容 Chat Completions 协议，支持模型发现、同型号去重、通道回退、工具调用及生成中止。
- **会话与性能**：scrypt 密码哈希、HttpOnly Cookie、账号与访客记录隔离，以及静态资源版本化、ETag 和压缩传输。

## 本地运行

环境要求：**Node.js 20 及以上**。

```bash
npm start
```

访问[登录首页](http://localhost:3000/login)，可注册账号或直接以访客使用。[接收工作台](http://localhost:3000/receiver)提供部门切换和处置流程演示。

### AI 配置

通过系统或进程环境变量配置密钥，变量示例见 [.env.example](.env.example)。程序不会自动加载 `.env` 文件；更新环境变量后需重启服务。

| 环境变量 | 默认 API 地址 | 用途 |
| --- | --- | --- |
| `FREE_API_KEY` | `https://api.fuka.win/v1` | 主通道 |
| `FREE_API_KEY_3` | `https://api.fuka.win/v1` | 扩展模型通道 |
| `FREE_API_KEY_2` | `https://jianzhile.vip/v1` | 可选扩展通道 |

可用模型取决于密钥权限与模型目录。未配置密钥时仍可浏览页面，AI 功能需有效配置。`PORT` 和 `DATA_DIR` 可分别指定端口与数据目录；默认数据保存在 `data/database.json`。

## 测试

```bash
npm test
```

覆盖报告处置、账号隔离、草稿同步、模型路由、流式响应及 Markdown 安全渲染等功能。测试使用独立临时数据和本地模拟模型服务，不消耗真实 AI 额度。

## 使用范围

项目用于学习与演示，仅使用虚构数据。接收端免登录，部门切换不构成正式权限控制；24 小时为演示处置时限。AI 提供辅助建议，处置结论由人工复核。
