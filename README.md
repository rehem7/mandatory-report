# 强制报告智能体

面向未成年人保护场景的全栈 Web 演示项目，集成 AI 问答、情景实训、普法学习与线索报告，贯通公众报告、人工复核、部门协同和监督反馈流程。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 智能问答 | 多模型切换与中文能力说明、流式回答、图片理解、来源检索及原话核对后生成报告草稿 |
| 情景实训 | 九个虚构案例，覆盖家庭冲突、网络侵害、多重风险与沉默回避，提供角色对话、评分和复盘 |
| 普法学习 | 阅读卡片后进入同主题选择题练习、自动评分与逐题解析、对应实训入口及知识掌握台账 |
| 线索报告 | 地区联动选择、多文件证据、草稿恢复、匿名报告与回执查询 |
| 接收工作台 | 人工复核、部门分流、处置记录、超期及不予立案监督摘要 |
| 账号与记录 | 邮箱注册、访客使用、数据隔离及登录账号跨浏览器同步 |

首次访问提供使用提示，各功能页均可打开高亮指引。证据支持照片、视频、录音及文档，最多 10 个文件，单个不超过 10MB、合计不超过 50MB。

对话转报告先展示候选字段与用户原话，区分转述、推测和建议；用户逐项确认后才写入表单。实现与边界见[报告整理说明](docs/REPORT_DRAFT_IMPROVEMENTS.md)，后续案例资料接入见[案例库建议](docs/CASE_LIBRARY_PLAN.md)。

添加 AI 图片时会自动验证当前模型的图片支持，仅开放通过测试图验证的模型通道。支持 PNG/JPG/WebP，每条最多 3 张、单张 5MB、合计 10MB；图片不自动附入报告。第 2–9 项建议的实现及使用边界见[改进完成情况](docs/IMPROVEMENTS_STATUS.md)。

## 技术实现

- **服务端**：Node.js 原生 HTTP 服务，采用模块化结构组织认证、报告、问答和实训接口，无需安装运行依赖。
- **前端**：原生 JavaScript、CSS 与 SVG，提供响应式页面、Markdown 渲染和 SSE 流式交互。
- **数据管理**：JSON 文件持久化；结合 localStorage、IndexedDB 和服务端版本检查，实现草稿恢复与并发编辑保护。
- **AI 集成**：兼容 Chat Completions 协议，支持模型发现、同型号去重、通道回退、工具调用及生成中止。
- **会话与性能**：scrypt 密码哈希、HttpOnly Cookie、账号与访客记录隔离，以及静态资源版本化、ETag 和压缩传输。

## 本地运行

环境要求：**Node.js 20 及以上**。

```bash
npm start
```

访问[登录首页](http://localhost:3000/login)，可注册账号或直接以访客使用。[接收工作台](http://localhost:3000/receiver)提供部门切换和处置流程演示。

首页底部的“重置演示数据”会重建 6 条带有独立标记的虚构接收样例，覆盖公安待接收／待分流、民政、教育、妇联和超期检察监督。重复重置仅替换这些生成样例，保留已有提交、账号、对话及草稿。公众新提交仍统一进入公安队列，民政、教育和妇联仅接收经公安人工确认 B 类后分流的脱敏摘要。

### AI 配置

通过系统或进程环境变量配置密钥，变量示例见 [.env.example](.env.example)。程序不会自动加载 `.env` 文件；更新环境变量后需重启服务。

| 环境变量 | 默认 API 地址 | 用途 |
| --- | --- | --- |
| `FREE_API_KEY` | `https://api.fuka.win/v1` | 主通道 |
| `FREE_API_KEY_3` | `https://api.fuka.win/v1` | 扩展模型通道 |
| `FREE_API_KEY_2` | `https://jianzhile.vip/v1` | 可选扩展通道 |
| `DEEPSEEK_API_KEY` | `https://api.deepseek.com/v1` | DeepSeek V4.1 Flash、V4 Pro 官方通道 |

Windows 下优先使用显式传入的进程变量（空值表示禁用该密钥），未传入时依次读取用户和系统环境变量。配置官方 DeepSeek 密钥后，新对话默认使用官方 Flash。Flash 根据官方目录选择 `deepseek-flash-1017` 或 `deepseek-flash`，界面统一显示为 DeepSeek V4.1 Flash。目录可读取不代表聊天额度可用；余额不足、无可用通道和鉴权失败会分别提示。

模型列表仅保留官方 DeepSeek V4.1 Flash 和 DeepSeek V4 Pro；其他通道的目录不会添加到可选列表中。未配置官方密钥时仍可浏览页面，AI 功能需有效配置。`PORT` 和 `DATA_DIR` 可分别指定端口与数据目录；默认数据保存在 `data/database.json`。

```bash
npm test
```

覆盖报告处置、账号隔离、草稿同步、模型路由、流式响应及 Markdown 安全渲染等功能。测试使用独立临时数据和本地模拟模型服务，不消耗真实 AI 额度。

## 使用范围

项目用于学习与演示，仅使用虚构数据。接收端免登录，部门切换不构成正式权限控制；24 小时为演示处置时限。AI 提供辅助建议，处置结论由人工复核。
